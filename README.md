项目更新日志

### ver0.6.1 
内容更新
1. 从这个版本开始维护更新日志
2. 新增简单 / 困难模式
    - 简单模式：仅包含六星干员
    - 困难模式：包含五星干员

内容更新
1. 新增主界面 & 开始游戏界面

### ver1.0.1 
内容更新
1. 新增双人联机功能（测试版）
    - 使用免费公共 PeerJS 服务 `^0.peerjs.com`
    - 公共服务器偶尔不稳定，遇到连接问题重试即可
2. 多人模式规则：「简单 / 困难」难度由房主决定
3. 新增功能：对手色块猜测结果（匿名）、大局记分、再来一局
